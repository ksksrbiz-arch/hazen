# Brad Hazen — agent website scaffold

Phase 1: marketing and lead-generation website closely matching Realty Pro’s layout and visual direction. No accounts or MLS integration. Not production-ready and not deployed.

Run `npm run build`, then `npm run preview` and open http://localhost:8000. No dependencies are required. Edit `src/content.json` and `src/styles.css`; build generates physical route directories for refresh-safe navigation.

Start with [the project plan](docs/PROJECT_PLAN.md). Contact details and brokerage name were transcribed from Brad’s supplied card. Current credentials, service areas, listing content and testimonials await confirmation. No fictional properties or reviews are supplied. Forms are deferred rather than pretending to deliver inquiries.
