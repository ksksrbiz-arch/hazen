# Brad Hazen — agent website scaffold

Phase 1: original marketing and lead-generation website inspired by Realty Pro's organization. No accounts or MLS integration. Not production-ready and not deployed.

Run `npm run build`, then `npm run preview` and open http://localhost:8000. No dependencies are required. Edit `src/content.json` and `src/styles.css`; build generates physical route directories for refresh-safe navigation.

Start with [the project plan](docs/PROJECT_PLAN.md). All contact details, service areas, brokerage credentials, listing content and testimonials await Brad's confirmation. No fictional properties or reviews are supplied. Forms are deferred rather than pretending to deliver inquiries.

Repository: https://github.com/ksksrbiz-arch/hazen (private). Client ownership remains to be agreed. No GitHub Actions.
